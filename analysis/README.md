# 音乐影响力分析 —— 完整分析文档

> 2021 ICM Problem D《The Influence of Music》
> 数据：`../data/`（四张表）　|　分析代码：本目录下 8 个 Jupyter notebook

---

## 1. 项目目标

量化「音乐影响力」：理解先前音乐如何影响新音乐与新艺术家，识别**演化**（evolutionary）与**革命**（revolutionary）两类趋势。

核心逻辑链：**用网络结构刻画「谁影响了谁」→ 用音频特征相似度验证「影响是否真实发生」→ 用时间维度区分「演化 vs 革命」。**

---

## 2. 数据口径（关键决策）

四张原始表：

| 文件 | 内容 | 规模 |
|---|---|---|
| `influence_data.csv` | 影响关系（influencer→follower），**唯一含流派字段** | 42,770 条边 |
| `full_music_data.csv` | 逐首歌 11 个音频特征 | 98,340 首 |
| `data_by_artist.csv` | 按艺术家聚合的特征均值 | 5,854 位 |
| `data_by_year.csv` | 按年份聚合的特征均值 | 1921–2020 |

**已拍板的口径：**

1. **艺术家主键**：以 `data_by_artist`（5,854 位）为锚，`genre`/`active_start` 从 `influence_data` 补入。`full_music_data` 用于歌曲级细节。
2. **`artists_id` 是数组格式**（`[178301]`），必须解析方括号后才能 join —— 这是第一道清洗坎（已实测：清洗后 influence ∩ full_music ≈ 5560）。
3. **网络方向**：influencer → follower 有向边，无权。
4. **相似度**：10 个连续特征做 Z-score 标准化，欧氏距离，`S = 1/(1+d)`（等权透明基线）；`popularity` 不进核心距离。
5. **类别特征**：`key`（调号）用类别分布表示，不当连续数值；`mode` 用大调比例。
6. **影响力指标**：出度（直接影响）、入度（被影响来源）、反向 PageRank（源头影响力）、三度影响力、跨流派多样性（DIG）。
7. **对照口径**：验证影响时，对照组 = 同流派同时代的「未记录关系」，而非「确定无影响」。
8. **革命判定**：先定义规则（特征向量距离在相邻时间窗出现显著跳变）再找变点。

## 4. 各小题建模思路

### 问题 1：影响力网络（`01`）
- 建 influencer→follower 有向图，统计节点/边/密度/度分布/连通性。
- 影响力指标：出度、入度、**反向 PageRank**（源头影响力）、三度影响力、跨流派多样性。
- 输出影响力排名，抽一个流派子网络可视化，区分「完整网络指标」与「子网络内部指标」。

### 问题 2：音乐相似度（`02`）
- 10 个连续特征 Z-score 标准化，构造艺术家画像（均值 + 标准差 + 作品数）。
- 相似度 `S = 1/(1+欧氏距离)`。
- 验证：**同流派内平均相似度 > 跨流派**，并用置换检验排除偶然性（注意：艺术家对共享节点，不能当独立观测）。

### 问题 3：流派比较（`03`）
- 流派画像热图；低方差特征 + 异常值区分流派。
- 流派间影响矩阵（按边汇总、按「可能连接数」归一化密度）。
- 并排比较「流派相似度矩阵」与「流派影响矩阵」；画流派特征时间轨迹。

### 问题 4：影响验证（`04`）
- 取双方都有画像的影响边作样本，为每条边匹配同流派同时代的「未记录」对照。
- 效应量 `ΔS = 记录关系相似度均值 − 对照均值`；特征级 `Δ_k` 判断哪些特征更「传染」。
- 排除共同合作歌曲对相似度的直接抬高。

### 问题 5：革命检测（`05`）
- 用 `data_by_year` 构造时间特征向量，计算相邻时间窗的特征向量距离，找显著跳变点。
- 识别革命期，对照社会/技术事件；革命者 = 高影响力 + 早期作品新颖性 + 后续传播。

### 问题 6：单流派动态（`06`）
- 选一个数据支持的流派（如 Blues 或 Jazz）。
- 分时期（按活跃年代）计算影响力排名与音乐画像，识别地位上升/下降的动态影响者，还原流派发展过程。

### 问题 7：文化影响（`07`）
- 计算跨流派边比例、流派传播方向、跨年代传播范围等传播指标。
- 把时间拐点对照社会/技术事件（互联网普及、二战等），区分「描述结果」与「因果解释」，讨论数据局限。

## 5. 数据与方法的已知局限

- `genre` 标签只在 `influence_data`，第 2/3/4 问只能覆盖约 5,600 位艺术家。
- `active_start` 是十年粒度，不能精确代表影响发生时间。
- 音频特征只覆盖音乐的部分维度（无歌词、旋律、和弦、音频波形）。
- `popularity` 是算法热度、随时间衰减，不能当历史影响力。
- 4,410 首多艺术家合作歌曲会同时计入多位艺术家，汇总时用分摊规则。
